## 了解我们的工作

参与技术公益可以从了解[团队协作](/zh/about/teamwork/)和[公益技术产品](/zh/about/pm/)开始。具体参与方式和项目需求需与项目维护者进一步确认；本页不承诺当前有开放的志愿者岗位或合作名额。

## 网站问题与建议

发现页面错误、失效链接，或希望改进网站内容，可以在[本网站 GitHub 仓库的 Issues](https://github.com/airdb-site/airdb.net/issues)中提交公开反馈，或查看已有讨论。提交反馈需要 GitHub 账号。

这是公开的网站反馈渠道，不是私人客服、紧急求助或捐款入口。请勿提交密码、访问令牌、个人隐私、受助者资料或未公开的安全漏洞细节。网站目前未提供经核实的私密联系入口。
